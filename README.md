

CleanPro Services is a modern and responsive cleaning service website designed to help customers discover professional cleaning services and easily request a cleaning.

## 🌐 About The Project

CleanPro Services provides a clean, simple, and professional online experience for customers looking for reliable cleaning services.

The website focuses on:

- Professional cleaning services
- Company information
- Our story
- Service details
- Cleaning bookings
- Responsive design
- Simple and user-friendly navigation

## ✨ Features

- 🏠 Professional homepage and hero section
- ℹ️ About CleanPro section
- 📖 Our Story section
- 🧹 Services section
- 📅 Booking section
- 📱 Responsive design for mobile, tablet, and desktop
- 🎨 Modern white, blue, and dark navy design
- ✨ Smooth hover effects and animations

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Design
- CSS Animations and Transitions
